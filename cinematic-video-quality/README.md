# 영상 변환 품질 전용 스킬

[SKILL.md](SKILL.md)부터 읽으세요. 영상 변환 프롬프트와 품질 팁·체크리스트만 모은 독립 패키지입니다. 전체100컷 제작 인계나 자동화는 포함하지 않습니다.

- [기존 프롬프트 원문](references/original-prompts.md)
- [강화 템플릿·변환 팁](references/prompt-engineering.md)
- [품질 체크리스트](references/quality-checklist.md)

설치: 이 폴더를 Codex skills 폴더의 cinematic-video-quality로 복사한 뒤 새 세션에서 `$cinematic-video-quality`를 호출하세요.
관측된 결함 기록을 바탕으로 작성했으며 새로운 A/B 생성 실험으로 검증한 품질 보장은 아닙니다. 이전480p H3 유료 관측은 H3 전체 유료를 뜻하지 않습니다. 현재 프로젝트는768p와 매 요청 무료 재확인이 필수입니다.

## 최신 사용자 정정
원래 세션의 극도로 빠른 속도와 연속 장면 변화가 선호 기준입니다. 이전 버전의 한 이동·한 공개 축소 권고를 철회했습니다. [속도 보존 규칙](references/speed-lock.md)을 먼저 적용하세요.
