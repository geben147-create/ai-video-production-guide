# 팁·검수 체크리스트

## 제출 전
- [ ] 실제 소스를 보았고, 얼굴/손/문/기둥 오류가 없다.
- [ ] 전경·중경·원경과 빈 이동 통로가 읽힌다.
- [ ] 각 이동의 목적과 연속 도착 목표가 명확하다.
- [ ] 빠른 이동과 가까운 전경을 지정했다.
- [ ] 원문에 있는 연속 공간 공개·급강하·뱅크·상승을 인계 중 삭제하지 않았다.
- [ ] 유지할 구조·재질·광원을 이름으로 적었다.
- [ ] 다음 컷 앵커와 종료 방향을 지정했다.
- [ ] H3 768p 명시, 동일 전체 요청 무료 견적 두 번 통과.

## 생성 후: 전체 재생 + 시작/중간/끝
- [ ] 첫0.5초부터 실제 운동이 보인다. 문구만으로 합격하지 않는다.
- [ ] 가까운 전경과 먼 배경의 상대 이동이 구분된다.
- [ ] 광장이 다른 도시로 변하지 않고 기둥·창·선체가 유지된다.
- [ ] 돌→금속, 천→연기, 사람 합체, 손 변형이 없다.
- [ ] 주 목표가 블러/입자에 가려지지 않는다.
- [ ] 원치 않는 얼굴이나 말하는 입이 없다.
- [ ] 태양 방향이 갑자기 뒤집히지 않는다.
- [ ] 끝에서 정지하거나 처음 장소로 되돌아가지 않는다.
- [ ] 앞뒤 컷을 붙여 눈의 위치·진행 방향·밝기 변화가 자연스럽다.
- [ ] 실제 대사 길이와 맞는다. 속도 조절만으로 부족한 나레이션 길이를 억지로 채우지 않는다.

## 문제→최소 수정
| 문제 | 수정할 것 |
|---|---|
| 느린 시작 | 출발 묘사 제거, 첫 프레임 이동 명시, 가까운 전경 확보 |
| 형태가 녹음 | 원문 동선을 보존하고 문제가 생긴 물체의 기하·재질·접촉만 구체화 |
| 질감 소실 | 주 목표 블러 금지, 광원 고정, 재질 변경 금지 |
| 컷마다 리셋 | 동일 시작 이미지 반복 점검; 실제 마지막 프레임 또는 편집 전환 |
| 어지러움 | 속도 유지, 불필요한 roll/360도 회전 제거, 시선 목표 고정 |
| 얼굴 침입 | 카메라 동선을 인물에서 빼고 인물 크기를 작게 유지 |
| 후반만 변형 | 정상 구간만 잘라 사용 가능한지 먼저 검토; 원본 보존 |

## 비교 실험
같은 이미지·길이·해상도로 원문 프롬프트와 동선을 보존한 국소 수정본을 비교한다. 한 번에 한 요소만 바꾼다. 모델/해상도/프롬프트를 동시에 바꾸고 원인을 단정하지 않는다. 재생성도 무료 게이트 필수. 각 평가에 source hash, prompt, model/settings, 관찰 프레임, 결함 시작시간, 수정안을 기록한다.
2fps 표본은 빠른 결함을 놓칠 수 있다. 최종 승인에는 전체 프레임 속도 재생과 접합부 확인이 필요하다. ffmpeg decode는 파일 무결성 검사다.

## 인계 회귀 검사
- [ ] 원문 동작 동사와 순서가 모두 보존됨.
- [ ] 첫 프레임 속도, reveal 횟수, 전경 통과, 규모 변화가 줄지 않음.
- [ ] 정적인 구도/느린 팬/한 번의 얕은 상승으로 대체되지 않음.
- [ ] 새로운 모델에 맞춰 필드만 변경하고 연출을 요약하지 않음.
- [ ] 사용자 평가: 원래 세션의 역동성이 선호 기준임.
