단계별 적용

다음은 자료의 원칙을 사용자의 무료·일본어·최소 수동편집 조건에 맞춰 확장한 실행 설계입니다.

단계할 일남길 결과
1. 원본 컷을 분리컷 전환 없는 구간을 선택하고 원본 in/out, 시간 길이, FPS, 프레임 수, 오디오를 기록합니다. 가변 프레임 영상이면 원본 타임스탬프를 보존할 기준을 먼저 정합니다.원본 컷 계약
2. 변경 영역 명시공·의상·간판처럼 수정 대상과 제외 영역을 분리합니다. 전혀 다른 구도나 시간대가 필요한 작업은 VFX가 아니라 재연출로 분류합니다.target / preserve 목록
3. 원본 프레임에서 목표 제작원본 첫 프레임 또는 정확한 시각의 대표 프레임을 추출해 대상만 편집합니다. 중간 프레임을 참조하면 그 시각을 명시하고 새 시작 장면으로 오인하지 않게 합니다.클린 원본과 수정 예시
4. 기능·시간·비용 확인실제 video-edit/video-reference 모드인지 확인합니다. 원본 길이를 임의의 기본값으로 덮어쓰지 않습니다. 지원이 안 되면 클립 분할 또는 전통적 합성으로 검토하고 유료로 자동 전환하지 않습니다.정확한 요청·0원 확인
5. 한 컷 시험영상은 동작·카메라·시간의 참조, 이미지는 변경 외형의 참조로 지정합니다. 움직임·피부·제품·배경을 유지하고 화면 밖 대상은 보이지 않도록 합니다.원본과 후보 1쌍
6. 전체 길이 비교처음·중간·끝 샘플뿐 아니라 재진입·빠른 움직임·가림과 전체 재생을 확인합니다. 속도·동작 시각·사물 수가 바뀌면 수정 목적에 실패입니다. 필요하면 겹쳐 보기와 비수정 영역 차이 맵을 보조로 씁니다.EDIT_PASS / MOTION_DRIFT / UNINTENDED_CHANGE
7. 기존 편집에 복귀승인 후보만 동일 타임라인 자리에 교체하고 원본 음원을 유지합니다. 얼굴이 보이는 대사 컷이면 수정으로 입이 바뀌지 않았는지 립싱크를 다시 검사합니다.수정 컷과 변경 로그

원본 보존 VFX 요청
가이드 자체 작성 · 기존 컷의 국소 수정만 설계하라.
원본 영상={video_id}; 사용 구간={in/out}; 실제 길이={duration}; FPS/프레임 수={값}; 목표 이미지={image_id}; 이미지 시각={원본 타임코드}.

원본 영상은 모든 동작·속도·카메라·시간의 기준이다. 수정 이미지는 변경 대상의 외형만 지정한다.
재연출, 새 컷, 임의 줌, 시간 늘림/줄임, 대상 복제, 배경 소품 삭제, 다른 인물 생성 금지.
대상이 손/몸/물체 뒤에 있으면 정확히 가려지고 다시 나타날 때 정체성을 유지한다. 그림자·반사·접촉광은 장면에 맞게 처리한다.
실제 영상 수정 모드와 원본 길이 지원·현재 0원 견적을 확인한다. 불명확하면 제출하지 않는다.
최종 결과는 원본과 시간별 비교한 후에만 승인한다.

정해진 영역만 변경한다. 나머지 얼굴, 손, 의상, 도로/공간 구조, 주변 사물 수를 유지한다.
이 이미지는 기존 영상의 수정 예시이지 새 영상의 자유로운 키비주얼이 아니다.
원본과 나란히 비교하여 변경 영역 외에 달라진 항목을 보고하라. 불필요한 전체 리스타일링이 일어났다면 실패로 표시하라.
가림과 이동 방향이 읽히는 프레임을 쓰되 정확한 시작 프레임이 아니면 그 사실을 메타데이터에 표시하라.
텍스트·브랜드·사람의 초상은 허용된 범위 밖에서 추가하거나 바꾸지 마라.

가이드 자체 작성 · 입력={원본, 수정본, 컷 계약, 변경 허용 영역}.
1. 원본/출력 길이, FPS, 프레임 수와 타임라인 위치를 비교하라. 차이가 있으면 원인과 영향부터 설명하라.

3. 카메라·사람 동작·제품 형태·표정·입·배경 사물 수·그림자·반사를 검사하라.
4. 허용한 변화 / 의도하지 않은 변화 / 확인 불가로 구분하고 timecode와 사유를 남겨라.

6. 원본과 달라도 멋있다는 이유로 성공 처리하지 않는다. 얼굴 발화가 있으면 최종 WAV로 립싱크를 재검수한다.
