단계별 적용

다음은 자료의 원칙을 사용자의 무료·일본어·최소 수동편집 조건에 맞춰 확장한 실행 설계입니다.

단계할 일남길 결과
1. 작업 범위 고정프로젝트, 입력 asset_id, 파일 해시, 모델, 비율, 수량, 바꿀 요소와 유지할 요소를 명시합니다. 클릭되어 있다는 사실만 입력 근거로 삼지 않습니다.불변 입력 명세
2. 탐색·정본 분리외모를 바꾸는 탐색 후보는 DRAFT, 본편 캐릭터는 LOCKED로 분리합니다. 새 의상이나 연령대는 별도 버전으로 관리합니다.정본과 후보 폴더/ID
3. 한 축씩 변주9개 구도가 필요하면 wide·OTS·close-up 등 목표를 직접 할당합니다. “다양하게” 한 단어로 끝내지 않고 각 컷의 정보 목적을 적습니다.변주 매트릭스
4. 최소 수정·검수소품 교체는 소품만, 얼굴 수정은 승인된 얼굴만 연결합니다. 피부 보정으로 고유 특징이 사라지면 원본에서 다시 분기합니다.변경 전후 비교
5. 제출과 대기 분리미리보기·견적·실행을 구분합니다. 독립 작업은 병렬화할 수 있지만 마지막 프레임을 이어받는 체인은 순서대로 처리합니다. 자동 재시도 상한을 둡니다.노드 상태와 job_id
6. 스토리보드에서 편집으로나온 파일 수가 아니라 컷 간 시선·동작·길이를 확인합니다. 생성 5초가 최종 사용 5초라는 뜻은 아닙니다. 선택한 구간만 오디오 기준 타임라인에 넣습니다.선택 컷 목록과 편집표

복사해서 쓰는 프롬프트 3개

가이드 자체 작성 · 특정 플랫폼에 종속되지 않는 지시문입니다. 현재 지원 기능과 필드에 맞춰 변환하고 없는 기능을 발명하지 마세요.

입력 잠금·노드 작업 명세
가이드 자체 작성 · 이미지 작업 계획만 작성하라.
project_id={프로젝트}; input_assets={asset_id, 역할, 승인 여부, 해시}; 목표={목표}; 비율={비율}; 허용 모델={현재 검증된 모델}; 수량 상한={수량}; 추가 비용 상한=0.
각 작업에 node_id, input_asset_ids, operation, preserve, change_only, output_id, dependencies, expected_count, quote_status를 부여하라.
현재 선택된 UI 이미지나 이전 질문의 캐릭터를 입력으로 추정하지 마라. 명시 ID가 없거나 서로 다르면 INPUT_MISMATCH.
독립 작업만 병렬화하고 CONTINUE는 직전 컷 검수 뒤 실행하도록 순서를 세워라.
처음엔 작업당 1개 시험만 계획하라. 견적이 0이고 입력이 일치할 때만 허용된 범위에서 확장한다.
완료 job_id는 조회만 하며 결과 대기 중 같은 작업을 중복 제출하지 않는다.
8컷 스토리보드 변주
가이드 자체 작성 · 실제 생성 없이 8컷을 설계하라.
[입력] 사건={목표→장애→선택→실행→결과}, 승인 캐릭터={ID}, 장소={ID}, 영상 유형={광고/스토리/진행자}, 최종 음성={대사표}
각 컷은 shot_id, narrative_purpose, cast_ids, shot_size, camera_side, eyeline, action_in, action_out, next_transition, reference_roles로 작성한다.
같은 인물의 외모를 바꾸어 다양성을 만들지 않는다. 다양성은 샷 크기·시점·정보 공개·반응에서 만든다.
동작 연결 컷은 끝 상태와 다음 시작 상태를 짝짓고, 반응 컷은 듣는 인물의 입을 중립으로 둔다.
시청자에게 설명하는 컷도 일하거나 이동하는 행동을 포함하고, 매 컷 정면 독백을 반복하지 않는다.
각 컷의 예상 길이는 가안으로 표시한다. 실제 WAV/출력 미디어를 받기 전 타임라인 완료를 선언하지 마라.
한 부분만 바꾸는 이미지 편집
가이드 자체 작성 · 입력 이미지={승인 원본 ID}, 추가 참조={역할별 ID}.
유지: 인물 정체성, 인원수, 카메라 위치, 샷 크기, 배경 구조, 조명 방향, 손 점유, 변경 대상 외 의상·소품.
변경 대상={예: 머리 위 액세서리}; 변경 모습={구체적인 형태}; 변경하지 않을 주변={주변 요소}.
출력 비율과 해상도는 입력 계약을 유지한다. 다른 참조의 구도나 얼굴을 무단으로 가져오지 않는다.
자연스러운 가림, 그림자, 접촉점을 맞추고 텍스트·로고를 새로 발명하지 않는다.
이전 수정본을 반복 재가공하기 전 원본 대비 열화 여부를 검사한다. 전체 스타일·구도 변경이 필요하면 별도 작업으로 분리한다.
출력과 함께 실제로 바뀐 부분, 원치 않은 변화, 승인 필요 항목을 기록하라.
