왼쪽은 기존 방법 · 오른쪽은 추가 적용

기존 지침의 폐기가 아니라 보완입니다. 실제 본편에 반영했는지는 별도 컷 증거로 확인합니다.

기존 가이드새 자료의 보완이번 문서에 적용한 방법
기존: 일본어 WAV 우선·화자 ID·립싱크 검수추가: 음성 인상과 연기 지시를 분리한 소규모 후보 비교적용: 캐스팅 단계에서만 비교 → 승인 WAV 고정 → 같은 시간축으로 생성·편집
기존: 캐릭터 정본·독립 체인·중복 생성 방지추가: 입력 자산 ID 잠금, 변주 축 지정, 노드별 상태 기록적용: 작업 요청 직전 입력 스냅샷 → 1개 시험 → 독립 작업만 확장
기존: 대본 모드·카메라·연속성·무료 게이트추가: 광고 브리프·사실 근거·키비주얼/수정 분업·실사 혼합적용: 브랜드 메시지 → 시각적 증거 → 승인 컷 → 그래픽·오디오·납품 검사
기존: 소품 잠금·카메라 4요소·동작 연결추가: 제품 정본 시트, 마스크/합성 분리, 반응이 시작되는 정확한 순간적용: 제품 고정 → 키 상태 설계 → 독립 컷/연속 생성 선택 → 타이밍·질감 마감
기존: 문제 컷만 수정·원본 보존·A/V QC추가: 단일 컷 VFX, 원본과 동일한 시간 계약, 비수정 영역 대조적용: 컷 분리 → 대표 프레임 편집 → 원본+목표 참조 → 전 구간 차이 검사
FIELD NOTES / TUTORIAL-ROUTE

실행은 이 순서로

모델 구매보다 먼저 자료·판단 기준·편집 계약을 고정합니다.

  1. 작품 유형·타깃·전달할 의미와 기존 자산 상태를 결정한다. 광고면 근거와 CTA를 추가한다.
  2. 캐릭터·제품·장소 정본과 컷별 키비주얼을 승인하고 참조 ID를 잠근다.
  3. 화자와 최종 음성을 결정하고 컷·동작·카메라·길이를 설계한다. 일본어 편집표를 준비한다.
  4. 일반 생성 / native audio / 실제 립싱크 / VFX를 구별하고 현재 무료 조건을 확인한다. 1컷 시험 후 필요한 범위만 확장한다.
  5. 정확한 자막·로고·효과음·가림은 편집과 합성에서 처리한다. 기존 소스 중 정상 컷은 재생성하지 않는다.
  6. 전체 재생·발음·입·제품·연속성을 검수하고 미검증 상태를 숨기지 않은 산출물과 ZIP을 전달한다.
무료 전용: 참고 영상은 여러 유료 서비스를 소개합니다. 이 사이트는 해당 서비스가 무료라고 보증하지 않습니다. 실행 직전 정확한 요청이 0원으로 확인되지 않으면 제작은 중단하고 기존 자산 편집·설계만 진행합니다. 이번 업데이트는 가이드 공개 작업이며 영상 생성·TTS·립싱크 작업을 실행하지 않았습니다.
