이 지시문은 특정 모델을 강제하지 않습니다. 먼저 연출 계획을 만들고, 그다음 프로젝트와 제공자 어댑터가 실제 프롬프트로 번역하게 합니다.

범용 영상 문법 적용 지시문

이미 완료된 생성물을 무조건 폐기하지 않고, 먼저 샷 단위로 ACCEPT / EDIT / REGENERATE를 판정합니다. 가장 큰 차이는 “무슨 모델을 쓰는가”가 아니라 “앞 컷의 어떤 정보를 다음 컷이 이어받는가”입니다.

🔴 금지

모든 컷 정면 구도, 같은 샷 크기 반복, 위치 순간이동, 행동 재시작, 모든 대사의 카메라 응시, 불연속을 디졸브로 숨기기.

현재 영상의 모델을 먼저 바꾸지 말고 영상 문법부터 재설계하라.

1. 모든 대사를 PRESENTER_ADDRESS / IN_WORLD_EPISODE / BRIDGED_EPISODE / VOICE_LED_MONTAGE / NO_DIALOGUE 중 하나로 분류한다.
2. 각 장면에 STORY_FUNCTION, SHOT_SIZE, CAMERA_POSITION, SPATIAL_ANCHOR, SCREEN_DIRECTION을 기록한다.
3. 같은 장면의 연속 컷은 같은 샷 크기를 반복하지 않는다. WIDE → OTS → MEDIUM → INSERT → REACTION 흐름 중 의미에 맞는 변주를 사용한다.
4. 장소 기준 이미지는 정면 미장센만 만들지 말고 높은 3/4 또는 측면 공간 마스터를 함께 준비한다. 출입구·카운터·인물 위치·이동 경로를 명확히 표시한다.
5. 각 영상 프롬프트는 PREVIOUS_STATE → START_STATE → SINGLE_ACTING_BEAT → SPEECH → PHYSICAL_ACTION → CAMERA → END_STATE → CONTINUITY_HANDOFF → NEGATIVE 순서로 작성한다.
6. 걷기·들기·돌기 같은 행동은 앞 컷에서 시작하고 다음 컷에서 마무리하는 CUT_ON_ACTION으로 설계한다.
7. 인물이 공간을 이동하면 지나치는 몸, 이동하는 시선, 손·발, 소품, 오프스크린 소리 중 하나로 시간과 거리를 연결한다.
8. 두 사람이 같은 공간에 있음을 보여야 하면 OTS, 전경 실루엣, 시선 매치 중 하나를 공간 앵커로 사용한다.
9. CONTINUE 컷만 이전 영상의 검증된 END HOLD 프레임을 다음 시작 이미지로 사용한다. LOCATION_CUT, TIME_JUMP, REACTION_CUT, MATCH_CUT에는 독립 시작 이미지를 허용한다.
10. 화면에 보이는 인물이 말하면 최종 TTS 오디오 참조 립싱크를 사용한다. 반응이 핵심이면 듣는 인물의 얼굴을 보여주고 화자는 화면 밖에 둔다.
11. 시청자 설명은 속삭이는 혼잣말이 아니라 상황→선택→결과를 명확히 말한다. 설명 후에는 극중 행동으로 복귀한다.
12. 립싱크 QC와 연출 QC를 분리한다. 입이 맞더라도 시선·표정·행동 목적·공간·시간 연결이 틀리면 실패다.
13. 기존 컷을 ACCEPT / EDIT_ONLY / REGENERATE로 분류하고 실패 컷만 다시 생성한다.
14. 장르 색감과 재질은 PROJECT_STYLE_ADAPTER에 두고, Pollo/MiniMax/Kling 필드와 비용은 PROVIDER_ADAPTER에 둔다. 범용 연출 코어에 특정 모델과 라멘 스타일을 하드코딩하지 않는다.

결과는 장면별로 다음을 보고하라:
scene_id / narrative_mode / story_function / shot_size / spatial_anchor / action_phase / transition_type / previous_state_out / current_state_in / audio_lipsync / QC 판정 / 재생성 여부.
