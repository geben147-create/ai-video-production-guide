길이·자동 편집

목적별 초수·타임라인·본편 자산

PURPOSE DRIVES TIME

길이는 감이 아니라 설계

모델의 최대 길이를 다 쓰지 않습니다. 한 컷에 담긴 단일 사건이 끝나는 데 필요한 시간만 줘야 모델이 빈 시간을 임의 행동으로 채우지 않습니다.

💗09 · 목적별 컷 길이
3–4s

사물·인서트

손, 음식, 주문표, 문고리, 발. 정보 하나를 정확히 전달.

5–7s

이동·액션

걷기, 들기, 포장, 전달. 시작과 끝이 보이는 단일 행동.

7–10s

감정·대사

실제 TTS 길이 + 짧은 반응 여백. 보이는 화자만 립싱크.

5–8s

설정 샷

장소·거리·인물 배치를 읽을 충분한 시간.

10s+

의도된 롱테이크

카메라 무브는 하나. 서사상 중단하지 않아야 할 이유가 있을 때만.

💗10 · 환각 방지
30초 요청 ≠ 30초 분량의 실제 사건
남는 시간을 AI가 정적·유령 동작·새 사건으로 채우지 않게 짧게 쪼갭니다.
💗10 · 수정 비용
긴 클립 전체 재생성 → 실패한 짧은 컷만 교체
크레딧·대기 시간·수동 편집 범위를 동시에 낮춥니다.
FIELD NOTES / EDIT-MAP

자동 편집용 시간표

실제 대사 길이와 최종 화면 유지 길이를 기준으로 생성 길이·소스 사용 구간을 구분합니다.

  1. 컷 표에 timeline_start/end, source_in/out, wav_start/end, fps, scene_id, line_id를 기록한다. 빈 구간·겹침·오디오 잘림을 검사한다.
  2. 💗09의 3–10초는 참고 영상이 제안한 생성 단위의 출발점이다. 최종 편집은 강한 대사 2–4초, 일반 대화 3–5초, 반응 0.7–2초, 음식 1–3초 등 목적에 맞게 더 짧게 쓸 수 있다. 고정 규칙으로 모든 컷을 자르지 않는다.
  3. 무료 생성이 5초만 가능하면 정확한 견적 조건 안에서 짧은 컷을 생성하거나 인서트를 조합한다. 입이 보이는 대사를 5초 영상 타임리맵만으로 8초로 늘리지 않는다.
  4. 기존 107개 자료의 예시 분류는 캐릭터 13·장소 10·소품 20·본편 64다. 본편만 요청하면 시트는 참고용으로 보관하고 영상 생성 큐에 넣지 않는다. 전량 사용 요구가 있으면 사용처 또는 미사용 사유를 장면 장부에 기록한다.
  5. 자막·숫자·효과음은 후편집에서 넣는다. 음성을 선명하게 유지하고 배경음악을 낮춘다. 얼굴 발화·반응·손·음식·현장 소리의 역할을 구별한다.
  6. HyperFrames 또는 로컬 렌더러에 확정된 컷 표를 전달해 전체 타임라인을 자동 조립한다. 한국어 검수본, 일본어 최종본, SRT/편집 CSV를 같은 ID 체계로 출력한다.
  7. 완성 MP4 전체 decode, 검은 화면·정지 화면·소리 중복·경계·자막 안전영역을 검사한다. 원본 클립의 QC만으로 최종 편집본 합격을 선언하지 않는다.
