제작 순서

대본과 최종 음성에서 시작해 검증된 컷을 편집합니다.

  1. 대본: 시청자 설명·극중 대화·몽타주·무대사 구분.
  2. 캐릭터와 장소: 정체성·공간·동선을 보여주는 승인 참조.
  3. 카메라: 움직임·속도·프레이밍·종료점과 목적별 길이.
  4. 음성·생성: 일본어 WAV 실측, 현재 무료 견적·기능 확인, 립싱크.
  5. 연결·편집: 실제 프레임과 상태 전달, 한국어 뜻·발음·컷 ID 대조.
  6. 검수·전달: 실패 컷만 수정하고 완성 MP4·편집표·자막·ZIP 검증.
💗01~13은 두 번째 참고 영상에서 확장한 항목, 💗14~18은 신규 다섯 영상에 대응하는 문서 추가 번호, 💗19는 무편집 설계 자료에 대응하는 번호입니다. 기존 17개 비교와 V1/V2 기록도 보존했습니다. 이 사이트는 제작 지침이며 새 영상 생성이나 특정 모델의 무료·립싱크 인증 결과가 아닙니다.
