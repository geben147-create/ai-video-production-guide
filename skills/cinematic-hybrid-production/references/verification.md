# 검증 기록 · v2.1 · 2026-09-09

필수 배분과 이미지 적용 대상 선정을 강화한 v2.1 검증이다. 실제 영화·사진 모션을 렌더한 품질 평가가 아니다.

- skill-creator의 quick_validate.py: YAML frontmatter·이름·스캐폴드 검사 통과.
- 범용 100장면 예시: 영상 70, 사진 30, 500초, 최소 생성 단위 70 확인.
- 기존 배분 재현: 영상 72, 사진 28, 510초, 최소 생성 단위 73 확인. 원본 계획을 직접 집계한 영상 시간은 365초, 사진 시간은 145초.
- 다른 주제·길이: 과학 설명용 12장면·60초·서로 다른 길이의 장면에서 반올림한 8개 영상 / 4개 사진 배분과 생성 단위 계산 확인.
- 오류 주입: 초반 사진, 후반 보호 하이라이트의 사진 전환, 타임라인 틈, 중복 장면 ID, 영상 생성 단위 부족, 사진에 생성 단위 지정, 잘못된 물리 연결 선행 장면, 총길이 불일치를 각각 거부함.
- 영상 100%로 바꾼 계획을 오류로 거부함. v2의 권고 경고 방식은 제거했으며, 실제 영상 수가 고정된 video_scene_count와 달라도 실패함.
- 추가 오류 주입: 사진 허용 목록과 실제 모드 불일치, 빈 선정 이유, 새로운 행동이 필요한 사진 장면, 임의의 기본 영상 수 변경, 근거 없는 user_confirmed 배분을 거부함.
- --execution 검사: 파일 미지정·이미지 미검수 후보를 거부하고, 지정 파일과 검수 기록이 모두 있는 테스트 자료는 통과함. 검수 완료 표시가 있어도 소스 파일 이름이 비면 실패함. 테스트의 파일·검수 기록은 모의 데이터이며 실제 이미지를 검수했다는 뜻이 아님.
- 원문: 직접 연 자료의 공개 텍스트와 인용문 10개를 대조. 각 출처당 원문 인용은 6–19단어이며, 서로 떨어진 문장을 합성하지 않음.
- 스킬의 Markdown 내부 상대 링크가 실제 파일로 연결됨을 확인.

위 자동 검사는 총 22개 시나리오·무결성 항목을 통과했다. 공개 기사·전사문을 텍스트로 확인했으며, 해당 인터뷰 영상의 전체 청취·타임코드 검증은 하지 않았다. 전체 기사와 전체 전사문은 저장소에 배포하지 않는다.

미검증: 실제 이미지·영상 품질, 실제 클립 이음부, 내레이션·음악 믹스, 현재 모델 가격·무료 견적, 개별 자산의 사용권. 제작 실행 시 해당 프로젝트에서 검증해야 한다.
