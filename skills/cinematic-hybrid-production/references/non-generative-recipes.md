# AI 영상 모델 없이 만드는 후반 연출 12가지

**적용 범위는 SKILL.md 최우선 규칙의 사진 효과 허용 목록에 지정된 이미지뿐이다. 이 레시피를 전체 장면이나 AI 영상용 원본 이미지 전체에 일괄 적용하지 않는다. 실제 이미지를 보고 선정 이유를 기록한 뒤 적용한다.**

이 문서는 스킬이 제안하는 실행 레시피다. S01–S10은 sourcebook.md의 직접 인터뷰·기고를 뜻한다. 기법의 구체적인 시간·레이어·줌 수치와 도구 조합은 **본 스킬의 적용 추론**이며 감독의 직접 발언이 아니다. 현재 보유한 도구와 자료로 가능한 레시피를 선택한다.

## R01 · 의미를 따라 움직이는 사진

대본의 핵심 명사에 표시를 하고 해당 사진에 실제 존재하는 단서를 찾는다. 시작 구도와 도착 구도를 먼저 정한다. 예를 들어 작은 균열 → 균열이 있는 부재 → 부재를 지탱하는 전체 구조 순서로 관계를 공개한다. 처음부터 전체를 보여주면 공개할 정보가 없어지는지도 검토한다.

5초 출발 예: 0–0.8초 시작 정보를 읽음, 0.8–3.8초 새 정보까지 이동, 3.8–5초 도착점을 읽음. 천천히 일정하게 줌만 넣기보다 필요에 따라 세부 컷에서 전체 컷으로 한 번 전환한다. 확대율 3–8%는 작은 움직임의 후보일 뿐이며 정보 공개가 목적이면 다른 크롭을 선택한다.

실패 조건: 원본에 없는 정보를 공개한 것처럼 보임, 확대 후 글자가 읽히지 않음, 사진이 지나치게 저해상도여서 얼굴·재질이 무너짐. 단서 없는 사진은 바꾸거나 움직임을 줄인다.

## R02 · 정교한 2.5D 시차와 제한된 프로젝션

준비 순서: 원본 보존 → 전경·주 피사체·후경 등 의미 있는 마스크 분리 → 가려진 배경 복원 → 카메라가 볼 영역의 여유 확보 → 깊이 배치 → 작은 움직임부터 검수. 3~5레이어는 시작점이며, 억지로 인물의 신체를 여러 장으로 쪼개지 않는다.

전경은 빠르게, 주 피사체는 비교적 적게, 먼 배경은 더 적게 이동한다. 속도는 모든 레이어의 동일 배율 확대가 아니라 상대 운동으로 읽힌다. 입체 프로그램을 쓴다면 카메라가 볼 수 있는 평면 범위 안에서만 움직인다. 한 장으로 90도 회전·건물 뒤편·인물 옆얼굴을 새로 보여주지 않는다.

제안 출발점: 주 피사체 기준 이동을 작게 두고 전경의 화면 횡단을 더 크게 설계한다. 가장 극단적인 중간·마지막 프레임에서 머리카락·난간·유리·그림자 경계가 버티는지 확인한다. 실패하면 큰 시차를 줄이고 R01 또는 R04를 택한다. 실제 기록 사진의 복원·가상 깊이는 출처 화면과 구별한다.

## R03 · 전경 차폐로 만드는 강한 공개

다음 정보를 가릴 이유가 있는 물체를 고른다. 기둥·지도 카드·문서 가장자리처럼 실제 입력에 있거나 설명 도해로 표시할 수 있는 요소를 사용한다. 출발 이미지를 움직여 전경이 화면을 덮는 순간 다음 배경으로 교체하고 같은 방향으로 벗어나게 한다.

전환은 짧고 도착점은 안정적으로 둔다. 출발 후보로 0.25–0.5초 차폐를 비교하되 대본과 프레임률에 맞춘다. 2.5D에서 만들기 어려운 큰 공간 비행은, 준비된 전경 통과 + 의미가 맞는 새 구도로 압축할 수 있다. 물리적으로 이어지지 않은 장소라면 editorial_cut이라고 기록한다.

실패 조건: 매 컷마다 검은 물체가 튀어나옴, 문이 닫혔는데 통과함, 차폐 뒤 같은 정보만 반복, 속도를 숨기려 과도한 블러 사용. 소리도 무조건 whoosh를 붙이지 말고 이동물·장소에 맞춘다.

## R04 · 시선과 모양을 맞춘 매치 컷

전후 이미지에 공통 형태·동작 방향·명암 덩어리·주목점을 찾는다. 축의 중심 → 바퀴의 중심, 지도상의 원 → 실제 시설의 원형 구조처럼 연결한다. 시간·장소가 바뀌는 경우 대본·날짜·자막으로 알린다.

주목점은 정규화 좌표 x/y로 기록하고, 다음 컷의 핵심 정보가 전 컷에서 보던 위치 근처에 놓이도록 크롭한다. 컷을 멈춰 보면 이미지가 같을 필요는 없지만, 정상 재생에서 시선을 다시 찾는 일이 줄어야 한다. 부드러워야 할 곳은 R09의 잔향으로 연결하고 강한 발견은 바로 자른다.

실패 조건: 모양을 맞추기 위해 역사적 형태를 왜곡, 엉뚱한 두 사건을 원인·결과처럼 연결, 텍스트 방향 반전. 이 기법은 출력 프레임이 일치하는 물리적 연속성이 아니다.

## R05 · 전후 비교를 발견으로 만들기

같은 장소·방향·대상인지 먼저 확인한다. 맞는 쌍은 크롭·회전·스케일을 정합한 뒤 차이를 가리는 마스크를 이동시켜 공개한다. 완전히 다른 시점이면 분할 화면 또는 명시적 컷으로 비교한다. 변형 워프로 변화가 실제보다 커 보이게 만들지 않는다.

처음에는 공통 구조를 보여주고 나레이션이 변화를 언급할 때 새 상태를 공개한다. 출처·날짜는 읽을 수 있는 위치에 둔다. 한 번에 여러 수치를 펼치지 않고 한 가지 차이씩 강조한다. 전후 이미지가 AI 재현이면 실제 기록 사진으로 표시하지 않는다.

실패 조건: 정합이 틀려 물체가 출렁임, 서로 다른 지역을 같은 장소로 표시, 효과가 비교할 부분을 가림. 과장된 몰핑보다 정직한 두 장 비교가 낫다.

## R06 · 국소 빛·대기·초점으로 시선 이동

사용할 밝기 변화의 원인을 먼저 정한다. 창문에서 들어오는 빛, 화면 밖을 지나는 광원 등 장면에 납득되는 것만 선택한다. 효과는 별도 레이어로 만들고 주목점 주변만 제한적으로 움직인다. 먼지·안개는 실제 광원과 공간이 있을 때만 매우 적게 쓴다.

깊이 레이어가 준비돼 있으면 초점 이동으로 전경에서 중경 증거로 시선을 옮길 수 있다. 얼굴·문서의 핵심 글자·구조를 흐리게 해놓고 감성이라고 부르지 않는다. 빛은 화면 전체 노출을 흔드는 대신 마스크와 연결하며 그림자의 방향을 유지한다.

실패 조건: 정지 인물에 조명이 움직여 얼굴 구조가 변한 듯 보임, 연기 출처 없음, 모든 사진에 같은 먼지, 광원 방향 불일치. 기록 증거에는 기본 비활성으로 두고 R11을 우선한다.

## R07 · 기존 영상으로 만드는 부분 루프

이미 허가받은 영상에서 물결·깃발·불빛처럼 반복 가능한 작은 구간을 찾아 그 부분만 마스크로 움직인다. 나머지는 해당 소스의 정지 프레임으로 유지한다. 정지 이미지 한 장만 있는 경우 수작업 입자·빛 연출은 R06으로 기록하며 새로운 실제 동작을 만들었다고 설명하지 않는다.

루프 시작·끝 상태와 밝기를 맞추고, 필요하면 겹침으로 연결한다. 흐르는 물·걷는 사람처럼 방향이 있는 동작을 왕복 재생해 되감기는 현상을 만들지 않는다. 소리의 루프도 별도로 이어 붙이며 이미지 루프 길이와 기계적으로 일치시킬 필요는 없다.

실패 조건: 연기 역행, 물체 순간 이동, 루프 경계 번쩍임, 얼굴·손의 부자연스러운 반복. AI 영상 새 요청 수는 0이지만 기존 소스가 AI 영상이었다면 원래 출처를 기록한다.

## R08 · 지도·단면·도해의 단계적 설명

위치 → 진행 경로 → 구조적 결과를 차례로 보여준다. 처음에는 위치를 잡게 하고, 대본에 맞춰 선을 그리며, 도착지에서 단면이나 비교 수치를 공개한다. 실제로 관측되지 않은 단면은 설명용 도해라고 표시한다.

레이어·벡터·키프레임으로 구현하며, 사용 환경에 맞춰 Fusion·Blender·HyperFrames 등을 선택한다. HyperFrames를 선택할 때만 해당 도구 스킬을 읽는다. 숫자·좌표·라벨은 편집 가능한 텍스트로 유지하고 생성 이미지의 글자를 그대로 쓰지 않는다.

실패 조건: 실제 지리와 틀린 경로, 구조 없이 표면을 뚫는 카메라, 설명보다 먼저 움직여 시청자가 의미를 놓침. 카메라를 고정하고 선·레이어만 움직이는 것이 더 명확할 수도 있다.

## R09 · 음향이 먼저 여는 장면

장면을 소리 없이, 화면 없이 각각 점검한다. 다음 공간의 소리를 먼저 들려주는 선행음(J-cut), 앞 장면의 목소리·환경을 다음 화면에 남기는 잔향(L-cut), 음악을 잠시 비우는 간격, 한 번의 임팩트를 선택적으로 조합한다.

제안 출발점: 선행 공간음 0.3–0.8초, 중요한 발견 직전 음악을 비우는 간격 0.2–0.6초. 이 수치는 인터뷰의 수치가 아니다. 이야기상 필요한 환경음은 남겨도 되며, 무조건 디지털 완전 무음으로 자르지 않는다. 급격한 오디오 절단에는 짧은 페이드를 검토한다.

소리 방향은 보이는 공간과 연결한다. 목소리를 듣기 어려울 정도의 저음·리버브를 피한다. 참고 영화의 곡이나 시그니처 소리를 복제하지 않고 라이선스를 확인한 별도 재료로 감정적 기능만 적용한다.

실패 조건: 매 장면 같은 저음 충격, 모든 박자마다 컷, 소리가 다음 정보와 무관, 실제 녹음과 창작 효과가 구분되지 않음. 시청자 오인을 낳는 가짜 증언·실제 대화 조작은 피한다.

## R10 · 리듬의 압축과 해방

같은 길이의 사진을 순서대로 나열하지 않는다. 처음에는 위치·관계를 읽게 하고, 다음에는 증거를 짧게 축적하고, 가장 중요한 장면에서는 다시 길게 머문다. 전체 길이는 유지하면서 하나의 장면 슬롯 내부를 여러 편집 비트로 나눌 수 있다. 슬롯·편집 컷·생성 단위의 수는 따로 센다.

예시 비트 1.8 → 1.2 → 0.8 → 2.2초는 6초 묶음의 자체 제안이다. 문자 정보가 많으면 읽는 시간을 우선한다. 큰 영상 하이라이트 직후 사진에 안정 시간을 주면 다음 상승이 더 크게 느껴질 수 있다. 계속 가속하거나 모든 영상에 speed-up을 걸지 않는다.

실패 조건: 감정 대신 속도만 높임, 두 번 봐도 원인·결과가 안 읽힘, 음악 박자 때문에 대본이 잘림. 출력과 같은 크기·속도로 보고 판단한다.

## R11 · 색·재질·그레인을 통제하기

먼저 밝기·화이트밸런스·흑백/컬러 자료의 연결을 맞춘다. 피부, 종이, 벽돌처럼 내용 이해에 필요한 질감을 남긴다. 원본이 서로 다르면 동일 LUT 하나로 덮는 대신 매체의 성격을 유지하며 명암·채도 관계만 조절한다.

그레인·비네트·광학 효과는 필요한 경우 최종 출력 크기에서 약하게 비교한다. 노이즈를 늘리는 것이 고급스러운 화면의 증거는 아니다. 이미지를 확대해도 없는 세부가 복원됐다고 표시하지 않는다. 자료 원본·수정본·재현 그래픽을 구분한다.

실패 조건: 검정이 막혀 증거가 안 보임, 과한 선명화 테두리, 피부 플라스틱화, 필름 그레인 뒤에 숨은 저해상도, 흑백 자료의 임의 채색을 실제 색으로 표시.

## R12 · 결론을 읽는 시간

핵심 증거·결과를 보여주는 순간에는 움직임과 소리를 줄여 의미를 읽게 한다. 움직임이 적다는 이유로 클립을 실패라고 판단하지 않는다. 정적인 증거는 사진으로 끝낼 수 있고, 실제 행동이 해결하는 클라이맥스는 보호된 영상으로 남긴다.

앞부분에 있던 이미지·소품·소리를 마지막에 다시 사용한다면 그 의미가 무엇이 달라졌는지 대본으로 확인한다. 해결을 숨기는 예고편은 궁금증을 남길 수 있지만, 설명 다큐의 약속한 답까지 생략하지 않는다.

실패 조건: 결론에 새로운 정보가 과밀, 읽기도 전에 페이드아웃, 참사·추모 장면에 과장된 승리 음악, 단지 카메라를 멈췄다는 이유로 감정이 생겼다고 평가.

## 구현 참고 — 공식 문서

아래는 구현 가능성을 확인하는 자료이며 위 10인의 발언을 입증하는 출처와 다르다. 상용 전용 기능의 무료 사용 가능성을 추정하지 않는다. 설치된 버전·기능을 먼저 확인한다.

- [FFmpeg 필터 공식 문서](https://ffmpeg.org/ffmpeg-filters.html): zoompan, overlay, xfade, acrossfade, loudnorm 등의 입출력·옵션 확인. 필터 기능을 제공한다는 근거이며 특정 감독의 사용을 뜻하지 않는다.
- [Blackmagic Design — Fusion](https://www.blackmagicdesign.com/products/davinciresolve/fusion): 노드 합성, 키프레임, 2D/3D 요소 작업 설명. 유료 Studio 전용 기능은 자동 전제로 삼지 않는다.
- [Blender 4.2 LTS — Transparent Film](https://docs.blender.org/manual/en/4.2/render/cycles/render_settings/film.html): 투명 배경으로 렌더해 별도 합성하는 기능. 설치 버전에 맞는 매뉴얼로 재확인한다.

무료 경로의 예는 FFmpeg와 수작업 PNG 레이어, Blender 합성 또는 사용 가능한 Resolve 기능이다. 필요한 마스크·도해 준비에 시간이 든다는 점을 작업 계획에 반영한다. 레시피에 도구 이름이 있다고 실제 렌더·품질 검증을 완료한 것은 아니다.
