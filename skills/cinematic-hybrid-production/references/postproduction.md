# 후반부 제작 매뉴얼

## 실제 작업 순서

1. **타임라인을 잠근다.** 대본의 문장과 장면 시작·끝을 연결하고 후반 하이라이트 영상을 표시한다. 원본 영상과 이미지는 별도 보존한다. 남은 사진 슬롯에서만 후반 연출을 계획한다.
2. **사진 후보를 검수한다.** 출처·날짜·지역·형태·해상도·사용권과 대본 근거를 확인한다. 한 장에서 보여줄 핵심 정보가 없으면 효과를 넣기 전에 후보를 바꾼다. 사실 자료와 설명용 재현을 표시한다.
3. **각 장면의 공개를 한 줄로 쓴다.** '카메라가 움직인다' 대신 '이동하면서 이전에는 안 보이던 무엇이 드러나는가'를 쓴다. 시작·도착 시선 위치, 전경·주 피사체·배경, 음향과 다음 컷 관계를 장면 계약에 넣는다.
4. **효과를 고르고 재료를 만든다.** 주요 레시피 1개부터 적용한다. 시차에는 깨끗한 마스크·배경 복원·여유 화소가 필요하다. 입력이 부족하면 R01/R04/R09 조합으로 강도를 만든다. 효과 목적 때문에 새 역사·인물 행동을 만들지 않는다.
5. **낮은 해상도로 연출을 확인한다.** 실제 fps·최종 초수로 짧은 구간을 렌더해 정보 공개와 리듬을 확인한다. 방향이나 마스크가 실패하면 해당 부분을 수정한다. 저해상도 미리보기만으로 최종 질감 합격 표시를 하지 않는다.
6. **음향을 얹는다.** 음성, 공간음, 행동음, 전환음, 음악을 별도로 유지한다. J/L-cut, 정적, 임팩트가 설명을 돕는지 확인한다. 내레이션은 우선 명료하게 하고 음악을 무조건 크게 만들지 않는다.
7. **연결을 검사한다.** 사진↔사진 및 사진↔영상의 실제 이음부를 정상 속도로 본다. 컷이면 명시하고, 물리 연속이면 프레임·관성·빛을 확인한다. 디졸브로 줄어드는 시간이나 중복 음성을 정리한다.
8. **최종 크기에서 마감한다.** 색·질감·텍스트·마스크·잔상을 확인하고 납품 규격에 맞춰 인코딩한다. 최대 확대 구간에서 원본 화소가 충분한지 계산한다. 예: 출력 폭 1920에 1.1배 크롭이 필요하면 적어도 약 2112픽셀의 유효 폭이 필요하다. 과도한 확대는 원본 복원이 아니다.
9. **기록과 함께 납품한다.** 최종 파일, 편집 가능한 프로젝트/레이어, 장면 계약, 라이선스 표, 계획 검증·시각·음향 검수 결과를 함께 둔다. 해당 작업에서 만들지 않은 것은 생성·렌더 완료라고 표시하지 않는다.

## 30초 후반 시퀀스 설계 예 — 도시·시설의 변화

다음 수치는 레시피 적용 예시다. 특정 감독의 타임코드를 복제한 것이 아니며 실제 렌더본이 아니다. 동일 구조를 경제·과학·인물 이야기에도 주제에 맞게 치환할 수 있다.

| 슬롯 | 시간 | 모드 | 화면·소리 설계 | 기법 |
|---|---|---|---|---|
| A | 0–5초 | 사진 모션 | 이전 시대의 사진. 처음에 작은 일상의 흔적, 이후 전체 공간 공개. 다음 장면의 환경음을 0.4초 먼저 들려줌 | R01, R09 |
| B | 5–10초 | 사진 모션 | 현재 사진과 같은 주목점으로 매치. 정합이 가능하면 전후 차이를 2초에 걸쳐 공개 | R04, R05 |
| C | 10–15초 | 사진 모션 | 지도에 변화의 경로를 한 줄씩 표시. 마지막 0.4초 음악을 비우고 필요한 공간음 유지 | R08, R09 |
| D | 15–20초 | 보호 영상 | 주제의 핵심 행동·규모가 드러나는 영상. 앞 사진과의 관계가 물리적 연결이 아니면 명시적 컷 | 프로젝트 영상 연출 |
| E | 20–25초 | 사진 모션 | 영상의 결과를 보여주는 세부 증거. 깨끗한 전경이 있을 때만 시차. 화면 움직임을 점점 줄임 | R02, R11 |
| F | 25–30초 | 사진 모션 | 첫 소품/공간을 다른 의미로 다시 보여줌. 결론 문장을 읽을 시간과 소리 잔향을 남김 | R12 |

이 30초 예시는 **후반의 일부**라 사진 비중이 높다. 전체 작품을 1:5 영상/사진으로 바꾸는 비율 예시가 아니다. 전체 배분은 별도 70:30 목표 또는 승인 계획을 따른다.

## 장면별 계약 예 — 과학·기술

- 목적: 작은 부품의 변화가 시스템 전체에 미치는 영향을 이해시킨다.
- 시작: 화면 오른쪽 아래의 부품 접점. 도착: 접점에서 연결된 배선과 전체 장치. 자료가 실제로 그 관계를 보여주는지 확인한다.
- 입력: 고해상도 사진, 분리된 부품 PNG, 복원한 배경, 설명용 벡터 선. 레이어 준비가 안 되면 R01로 단순화한다.
- 움직임: 0–0.8초 접점을 읽음 → 0.8–3.6초 완만한 풀백과 선의 공개 → 3.6–5초 전체 구조를 읽음.
- 소리: 검증한 해당 환경음 또는 허가된 설명용 효과. 과학적 작동음을 지어내 실제 녹음으로 표시하지 않는다.
- 근거: S06의 사진 탐색 원칙에서 확장. 프레임 시간과 합성은 자체 설계다.
- 검수: 부품 형태 유지, 가려진 구멍 노출 없음, 정보가 대본 단어와 맞음, 다음 영상에서 시선 재탐색이 적음.

## 수준을 올릴 때 먼저 바꿀 것

우선순위는 소재·정보 공개 → 컷과 소리 → 깊이·마스크 → 색·질감이다. 같은 사진에 줌 폭·대비·비네트만 더하는 것은 장면의 정보량이나 감정 구조를 바꾸지 못할 수 있다. 높은 드라마는 빠른 이동 자체보다 예상·공개·결과의 대비에서 평가한다.

| 입력 상태 | 선택 | 보류할 것 |
|---|---|---|
| 깨끗한 평면 사진만 있음 | R01 + R04 또는 R09 | 큰 궤도 이동·새 행동 |
| 분리 마스크와 복원 배경 있음 | R02 + 필요한 국소 효과 | 가려진 공간이 드러나는 무리한 회전 |
| 실제 전후 사진 있음 | R05 + 날짜·출처 | 과장 몰핑 |
| 지도·도면이 정확함 | R08 + 음성 동기 | 장식용 카메라 비행 |
| 기존 허가 영상에 작은 반복 동작 있음 | R07 | 새 영상 생성 없이 새 인물 행동을 만든다는 주장 |
| 핵심 증거·추모·해결 | R11 + R12 | 무관한 충격음·먼지·빠른 흔들림 |

## 검수와 기록

검수는 실제 증거를 남긴다. shot_id, revision, 렌더 파일/해시, 검수 시점, 시작·중간·끝 확인, 정상 속도 재생 여부, 실패 프레임/시간, 수정 이유를 기록한다. 원본의 시간·장소·내용이 틀렸거나 마스크가 새는 경우는 점수 평균으로 통과시키지 않는다.

계획 단계의 점수는 설계 후보 비교에만 쓴다. 실제 출력에는 정보 가독성, 연출 목적, 깊이의 신뢰성, 시선·시간 연결, 음성 명료도, 질감 보존을 각각 검토한다. 'Netflix급', '영화급', '10인 감독 검수 완료' 같은 표현은 검증 상태를 대신하지 않는다. 이번 자료의 10인은 출처의 저자·인터뷰 대상이지 실제 리뷰에 참여한 팀이 아니다.
