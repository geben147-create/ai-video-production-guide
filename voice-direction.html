가이드 자체 작성 · 특정 플랫폼에 종속되지 않는 지시문입니다. 현재 지원 기능과 필드에 맞춰 변환하고 없는 기능을 발명하지 마세요.

화자 캐스팅 브리프
너는 일본어 영상의 캐스팅 디렉터다. 아래는 가이드 자체 작성 템플릿이다.
[입력] 작품={작품}, 화자={화자 ID}, 지각 연령대={연령대}, 성격={성격}, 관계={발화 상대}, 언어={ja-JP}, 샘플 대사={일본어 원문}, 허용 비용={0}
1. 음색(밝기·거칠기), 발성 강도, 말의 속도, 휴지, 감정을 각각 분리해 제안하라.
2. 동일 문장·동일 의미로 A 차분 / B 생동 / C 단호의 3가지 디렉팅을 작성하라. 이는 디렉팅 후보이며 3개 유료 생성 지시가 아니다.
3. 현재 사용 가능한 VOICEVOX 화자/style 목록이 제공되면 그 안에서만 후보 ID를 선택하라. 없으면 ID를 지어내지 말고 목록 확인 항목을 남겨라.
4. 일본어 원문 / 한국어 뜻 / 한글 발음(근사)을 나란히 출력하라. 한글 발음을 TTS에 넣지 마라.
5. 선정 기준은 발음 정확성, 역할 적합성, 문장 간 음색 일관성이다. 특정인의 목소리를 복제하지 마라.
[출력] 화자 프로필, 3개 디렉팅, 비교 체크표. 실제 합성·결제는 하지 마라.
Native audio 음성 오디션 지시
가이드 자체 작성 · 음성 생성 기능이 확인된 엔드포인트에만 적용.
역할={가상의 승인 화자}; 언어={언어}; 정확한 대사={원문}; 문맥={이전 사건}; 목표 정서={정서}; 상대={시청자/극중 인물}.
녹음실에서 자연스럽게 읽는 한 명의 화자. 단어를 바꾸거나 추가하지 않는다. 성대모사, 임의 감탄사, BGM, 중복 목소리, 과장된 숨소리 금지.
중요 단어={강조할 단어}; 휴지 위치={의도된 휴지}; 끝맺음={문장 끝의 정서}. 목표 구간={실측 대사 길이와 여유}.
보이는 입의 정확성보다 이번 단계는 음성 후보 평가가 목적이다. 얼굴 영상은 최종 본편에 자동 채택하지 않는다.
요청 전 현재 음성 생성 지원·입력 필드·계정·견적을 확인한다. 총 추가 비용이 0이 아니거나 불명확하면 COST_BLOCKED로 멈춘다.
완료 후 원문 대비 오류와 음질을 검사하고, 최종 승인 WAV 및 실제 길이를 반환한다.
음성·립싱크 인수인계
가이드 자체 작성 · 다음 자료로 음성 편집표를 만들어라.
[입력] 승인 대사표={표}, 최종 WAV 목록={목록}, 컷 목록={목록}, 프레임레이트={fps}
line_id, speaker_id, ja_text, ko_translation, ko_pronunciation, wav_version, actual_duration, timeline_in, timeline_out, shot_id, visible_speaker, audio_mode, qc_status를 출력한다.
원문과 다른 단어, 문장 끝 잘림, 화자 변경은 AUDIO_REVIEW. 보이는 입을 확인하지 않았으면 LIPSYNC_UNVERIFIED.
같은 음원 해시만으로 립싱크 PASS를 주지 마라. 시작·중간·끝의 입과 소리를 확인할 위치를 지정하라.
일본어를 모르는 편집자에게는 한국어 뜻·근사 발음과 컷 썸네일 ID를 제공하라. 근사 발음은 전문 일본어 검수를 대신하지 않는다.
대사 중 영상만 늘리거나 줄이지 않는다. 수정 필요 시 음성 우선으로 다시 정렬한다.
