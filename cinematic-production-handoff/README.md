# 시네마틱 이미지·무료 AI 영상 제작 인계 패키지

새 세션은 [HANDOFF.md](HANDOFF.md)를 먼저 읽고 [SKILL.md](skills/cinematic-production/SKILL.md)를 적용하세요.

범용 제작 규칙과 로마 프로젝트 상태를 분리했습니다. 100장의 이미지와 47개 영상 자체는 로컬 원본에 있습니다. 공개 저장소에는 제작 문서, 프롬프트, 스키마, 익명화한 진행 기록과 검증 도구를 제공합니다. 이 저장소만 복제하면 영상 파일까지 복구되는 것은 아닙니다.

- `skills/cinematic-production/`: 재사용 가능한 스킬, 이미지·영상 프롬프트 제작법, 운영 규칙
- `schemas/`: 장면 계약 JSON Schema
- `project/`: 100컷 대본·프롬프트 및 제작 기록, 완료 파일 해시 목록
- `scripts/validate_contract.py`: 장면·비용 게이트 예제 검증
- `HANDOFF.md`: 정확한 다음 행동과 알려진 미완료 사항

수치·렌즈·조명은 재현 제안입니다. 인용 출처를 특정 감독의 실제 설정으로 오인하지 마세요. 조회수는 보장할 수 없습니다.
