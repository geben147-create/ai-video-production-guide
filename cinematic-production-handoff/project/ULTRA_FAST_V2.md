# 로마 영상 제작 — 사용자 초고속 오버라이드 v2 적용

2026-09-09 사용자 지시를 이 프로젝트의 카메라·속도·강도·편집 규칙보다 우선한다. 비용 0 절대 규칙은 그대로 최우선이다.

- 모든 신규 영상은 첫 프레임부터 이미 극도로 빠르게 움직인다. 출발 대기·점진 가속·느린 푸시·호버·정지 종료 금지.
- 0.5~1.2초마다 전경 통과·가림·목표 공개·높이·방향·스케일 중 하나를 바꾼다. 1.5~2.5초마다 주요 정보 공개를 설계한다.
- 감속하고 회전하지 않는다. 관성을 유지한 채 뱅크·하강·상승·횡추적으로 방향을 바꾼다.
- 카메라 가까운 실제 문틀·기둥·밧줄·지붕·직물·물줄기로 속도와 깊이를 만든다. 공간 구조와 인간·동물 형태를 유지한다.
- 반복 드론 비행 대신 와이드→디테일→대규모 공개로 교차한다. 소품 매크로는 소품 크기에 맞는 빠른 상대 이동을 사용한다.
- 카메라 이동 이유는 대본의 정보·규모·원인과 결과 공개이다. 무관한 폭발·연기·동물을 추가하지 않는다.
- NORMAL FAST도 고속이다. 연출 분포 참고값 5% / 30% / 45% / 20%. 느림은 다음 충격을 위한 3~5% 이내만 가능하다.
- 속도 점수: 첫 움직임2·전경 패럴랙스2·변화 빈도2·방향 에너지1·스케일1·강한 공개1·속도 연결1. 설계 8/10 이상. 설계 점수와 실제 검수 점수를 혼동하지 않는다.
- 얼굴을 설명자로 내세우지 않는다. 인물은 이야기상 필요할 때 등·손·옷 디테일 또는 원경으로 유지한다. 고정 게임 시점과 아바타 양팔 금지.

## 실행 순서

1. 새 001 훅은 재사용한다. 원래 눈뜨기/천장 002와 인물 있는 창문 003은 영상 순서에서 제외한다. 원본 이미지 100장은 보존한다.
2. 사용자 절대 배분: 001·004~070·083·099는 실제 Pollo 무료 영상 70컷. 나머지 후반071~100의28컷에만 로컬 사진 모션·합성을 적용한다. 초중반 사진 대체 금지. outputs/render_mode_policy.json의 목록을 모든 제출 전에 확인한다. 독립 영상 컷만 병렬 생성할 수 있다.
3. 특정 클립을 실제로 연속 연결할 때만 앞 영상의 마지막 사용 프레임·시간·해시·움직임을 추출하여 입력한다. 의존 컷은 병렬 제출하지 않는다.
4. 우선 Wan 3.0 `wan-v3-0` / 480p / 5초 / 16:9 / audio false / output 1. 매번 동일 실제 요청의 계정 및 비용 견적 2회를 확인한다.
5. `discountCost == 0` 및 `activityInfo.activityMode == unlimited` 동시 확인 없으면 제출하지 않는다. 2026-09-09 실측에서 4·6·7초는 유료, 5초는 무제한이었으나 이 결과는 영구 허가가 아니다.
6. 독립 컷을 최대 4개까지 동시에 처리한다. 다른 프로젝트의 작업을 취소하거나 덮어쓰지 않는다. 서비스가 한도를 반환하면 새 제출을 멈추고 기존 작업 완료 후 이어간다.
7. `video_jobs/NNN.json`에 제출 전 intent, 정확한 입력, 계정 크레딧, 견적과 확인시각, 제출 후 task_id와 반환 내용을 기록한다. task_id 있는 컷은 재제출하지 않는다. 모호한 제출도 확인 전 재시도하지 않는다.
8. 생성 도구의 상태 위젯은 자동 갱신된다. 제출 후 상태 도구를 반복 조회하지 않는다. 필요 시 Pollo 결과/Assets 화면에서 실제 완료와 미디어를 확인한다.
9. 완료 MP4는 `videos/`에 저장하고 디코딩·길이·해시를 확인한다. 재생 또는 프레임 검수로 관찰한 사실만 기록한다. 프롬프트의 고속 지시를 달성 증거로 쓰지 않는다.
10. 5초 영상 원본과 대사별 최종 편집 길이는 별개다. 70개 기본 영상+후반28개 사진 모션의 편집 초안은 002·003 제외 후501초다. 영상 최소 커버리지 추정은89개5초 단위이며 실제 제출수와 다르다. 긴 대사의 추가 영상은 필요할 때 실제 마지막 사용 프레임을 검수하고 무료 조건으로만 확보한다. 초중반의 부족한 영상 길이를 사진으로 메우지 않는다.

완료 원본 보존, 순서별 자동 진행, 비용 0, 실제 검증을 유지한다. 승인 재요청·수동 업로드 요구 없이 가능한 자동 업로드 수단을 사용한다.
