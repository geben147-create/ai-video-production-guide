# 최종 검수와 수정 기록

100개 파일을 모두 열어 디코딩 가능 여부와 실제 크기를 확인했고, 파일 해시 100개가 서로 다릅니다. 생성 결과는 컷별로 눈으로 검토했으며 관찰 메모는 image_manifest.json에 기록했습니다.

최종 편집 프롬프트와 생성 원본의 경로는 correction_manifest.json에 남겼습니다. 이전 버전은 최종 100장에 포함하지 않았습니다.

화려함은 촬영 구도와 재질·빛의 설계로 강화했습니다. 건축 배치와 장식은 해석적 재현이며, 역사 건축의 실측 복원이나 고대의 실제 사진으로 제시하지 않습니다. 지도 컷은 공간 규모와 연결망을 위한 개념 배경입니다. 086의 확정 영토처럼 보이던 색 면과 경계는 제거했습니다.

017은 저수조로 물이 들어오는 모습입니다. 062의 완성 판테온과 077의 후대 천장 재현은 117년 당일 장면과 구분합니다. 064의 각인·책은 연구를 설명하는 생성 소품입니다. 068–072는 연구/재료 반응을 설명하는 재현과 개념 이미지이며 판테온의 정확한 배합이나 실제 실시간 반응 영상의 증거가 아닙니다.

전환 요소는 주피사체를 가리지 않는 가장자리·전경에 배치했습니다. 실제 영상화에서는 가림 전후의 대상 위치와 광원, 마지막 사용 프레임, 움직임 방향을 확인해야 합니다. 현재의 이동·광원 수치는 제작 제안이며 실제 촬영 메타데이터나 완성 영상의 측정값은 아닙니다.
