VOICEVOX·한국어 편집표·입 검수

FIELD NOTES / JAPANESE-AUDIO

일본어를 몰라도 편집하기

최종 일본어 음성, 한국어 뜻, 한글 발음, 이미지·영상 ID를 같은 대사 ID로 연결합니다.

  1. 일본어 대본을 확정하고 한 문장에 발화자·상대·감정·행동을 지정한다. 자연스러운 남녀 음색을 등장인물의 연령대·성격에 맞춰 샘플 비교한다. “유튜버가 가장 많이 쓰는 목소리”는 근거 없이 순위를 매기지 않는다.
  2. VOICEVOX 엔진 버전, 실제 speaker/style ID, 속도·피치·억양·휴지를 저장한다. 조연과 주연의 목소리 중복을 확인하고 승인된 화자 프로필을 유지한다.
  3. 일본어 원문 → 최종 WAV → 실제 시작·끝 시간 → 영상 생성/립싱크 → 편집 순서로 진행한다. 한글 발음은 이해용 근사 표기이며 TTS 입력은 일본어 원문이다.
  4. VOICEVOX 엔진의 audio_query와 synthesis를 사용하거나 UI로 합성한다. 정렬 정보는 실제 WAV를 기준으로 검증한다. 샘플 수·샘플레이트로 길이를 계산하고 계획 초수만 믿지 않는다.
  5. VOICEVOX 소프트웨어 약관과 선택한 캐릭터·음성의 개별 이용 조건, 크레딧 표기를 확인해 최종 제작 패키지에 기록한다.
대사 ID / 컷일본어한글 발음(근사)한국어 뜻화면 매칭 예시
L001 / S001今日は配達を始めます。쿄오와 하이타츠오 하지메마스.오늘은 배달을 시작합니다.주인공이 배달함을 준비하는 컷. 실제 WAV 측정 후 타임코드 입력.
L002 / S002これで準備はできました。코레데 준비와 데키마시타.이제 준비가 끝났습니다.포장 완료 손 인서트 → 주인공 짧은 반응.
편집표 필드: line_id / speaker / ja_text / ko_pronunciation / ko_translation / wav_file / start / end / image_id / clip_id / visible_speaker / narrative_mode / QC. 한국어 편집 확인본에는 세 줄 대조 자막과 컷 ID를 표시하고, 공개 일본어 최종본에는 필요한 자막만 별도 출력합니다. 예시는 새 제작 결과가 아닙니다.

같은 음원 사용은 필수지만 그 사실만으로 생성된 입의 정확성이 증명되지는 않습니다.

일반 영상 생성만 지원대사 컷은 최종 TTS 후 사용 가능한 립싱크 처리 단계가 필요.엔진이 없으면 LIPSYNC_BLOCKED. 입을 중립으로 생성해 TTS만 얹은 영상은 립싱크 완료가 아님.
