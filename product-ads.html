단계별 적용

다음은 자료의 원칙을 사용자의 무료·일본어·최소 수동편집 조건에 맞춰 확장한 실행 설계입니다.

단계할 일남길 결과
1. 제품 정본 구축앞·뒤·측면·기능부·질감·라벨의 승인 자료를 묶습니다. 라멘은 그릇 형태·토핑 수·색·배치가 정본입니다. 생성용 이미지와 글자/로고 후편집 파일을 분리합니다.product_id와 불변 특징
2. 전환의 양끝 설계가림→공개, 어두움→밝음, 전체→디테일 등 관객이 이해할 두 상태를 정의합니다. 동일 샷 연장인지 새 컷의 시각적 매치인지 선택합니다.상태 A/B와 전환 이유
3. 참조마다 역할 부여모델이 다중 참조를 지원하면 정체성·공간·동작 목표를 구분합니다. 모델에 없는 참조 필드를 지어내지 않습니다. 복잡한 동선 스케치는 설명용으로 두고 최종 시작 이미지는 깨끗한 판을 사용합니다.참조 역할표
4. 생성과 합성 분업정확한 글자, 삽입 화면, 제품 다중 배치는 레이어·마스크·트래킹을 사용합니다. 컷 하나로 안 되는 전환은 별도 컷으로 만들고 편집점의 빛·색·움직임을 맞춥니다.클린 영상과 합성 레이어
5. 반응 타이밍 지정“놀란다” 대신 “그릇을 들던 중 소리를 듣고 눈이 먼저 움직인다”처럼 순서를 적습니다. 코믹 반전은 제품 메시지를 훼손하지 않는 짧은 구간으로 시험합니다.행동→인지→반응 비트
6. 디테일과 소리 마감한 컷에 대표 카메라 움직임 하나를 중심으로 기능부를 보여 줍니다. 접촉음·옷 소리·조리음을 실제 접촉 시점에 붙이고, 사용 권리와 비용이 확인된 소스만 씁니다.디테일 컷·효과음 큐
7. 제품 불변성 최종 검사시작·중간·끝에서 부품 수·색·로고·크기·그립·그림자·가림을 봅니다. 화려하지만 제품이 다른 컷은 채택하지 않습니다.제품별 비교 QC

1. 동일 샷 CONTINUE / 상태 연결 생성 / 독립 컷 MATCH_CUT / 후반 합성 중 적합한 경로를 고르고 이유를 적어라.
2. CONTINUE라면 실제 이전 출력의 검증된 마지막 프레임을 입력으로 사용하라. 새 각도 컷이면 승인된 새 구도와 동작 위상을 맞추어라.
3. 각각 reference_identity, reference_environment, reference_action_goal의 역할을 명시하되 지원되지 않는 API 필드는 만들지 마라.
4. 화살표/번호 이미지는 동선 설명용이며 최종 영상에는 표시하지 않는다. 입력 방식이 불확실하면 스케치를 텍스트 동작 지시로 번역하라.
