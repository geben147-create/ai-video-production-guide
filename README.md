# AI 영상 제작 가이드

[공개 웹사이트](https://geben147-create.github.io/ai-video-production-guide/) · [한 페이지 통합판](https://geben147-create.github.io/ai-video-production-guide/complete.html) · [전체 ZIP](https://github.com/geben147-create/ai-video-production-guide/releases/latest)

기존 17개 비교와 💗01~13 추가 원칙을 보존한 한국어 제작 가이드입니다. 캐릭터·이미지, 카메라, 연속성, 연기, 일본어 VOICEVOX·립싱크, 자동 편집, 무료 조건·n8n 자동화, 복사 지시문과 QC를 제공합니다.

- [광고·기획 · 💗16](advertising.html): 키비주얼·부분 수정·영상화·후반 작업을 나누는 상업 제작 관점. 광고의 전달 목표를 먼저 설계하고, 실사와 AI를 역할에 맞게 섞는 범용 제작 절차로 정리했습니다.
- [제품·연출 · 💗17](product-ads.html): 제품을 고정한 채 배경·동작·효과를 분리하고, 편집과 합성으로 연결하는 사례. 특정 브랜드 광고의 장면을 복제하는 대신 정체성 보존·타이밍·가림·정보 전달 원칙으로 확장했습니다.
