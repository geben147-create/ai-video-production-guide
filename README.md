# AI 영상 제작 가이드

[공개 웹사이트](https://geben147-create.github.io/ai-video-production-guide/) · [한 페이지 통합판](https://geben147-create.github.io/ai-video-production-guide/complete.html) · [전체 ZIP](https://github.com/geben147-create/ai-video-production-guide/releases/latest)

## 실행

정적 HTML입니다. 다운로드한 폴더의 index.html을 브라우저로 열거나 GitHub Pages를 사용합니다. 외부 패키지·로그인 없이 내용 열람이 가능하며 체크 상태는 로컬 브라우저에만 저장합니다.

## 기록과 출처

과거 제작의 완료·비용·모델 기능 표시는 당시 보고입니다. 현재 기능과 무료 조건은 실제 요청 전에 확인합니다. [출처 페이지](sources.html)에 두 참고 영상과 공식 문서를 연결했습니다. 원본 영상·전체 자막·개인 계정·토큰·로컬 경로는 포함하지 않습니다. 공개 안내가 외부 영상·캐릭터·음성 자산의 재사용 권리를 부여하지 않습니다.
