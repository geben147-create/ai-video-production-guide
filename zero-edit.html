- 어렵지 않게 설명

STEP 1. FACT CHECK
각 주장에 [A] 1차/동시대 자료 [B] 유력한 학술적 사실 [C] 학계 이견 [D] 후대 전승 [E] 오류/근거부족 라벨을 붙인다.
C/D는 "대체로", "기록에 따르면", "전해집니다", "여러 해석이 있습니다"로 조정한다. E는 삭제하거나 질문형으로 바꾼다.
🦸‍♂️🦸‍♂️🦸‍♂️ A1: 라벨 근거 사료를 함께 적고 없으면 "확인 불가"로 적는다. 숫자는 계산 전제를 밝힌다. 후계자 시대의 성과를 창업자의 문장으로 쓰지 않는다.

STEP 2. SCRIPT SEGMENTATION
1~2문장을 하나의 시각 단위로 쓰되 의미가 이어지면 억지로 자르지 않는다.
각 장면: Scene # / Narration / Duration / Visual / Character / Prop / Location / Historical risk
🦸‍♂️🦸‍♂️🦸‍♂️ E1·E4: 나레이션 실측 초수를 적고 Duration과 20% 이상 차이 나면 표시한다. 문장 끝과 전환 지점을 일치시킨다.

STEP 3. CINEMATOGRAPHY
Extreme Wide / Wide / Medium / Medium Close / Close Up / Extreme Close Up / OTS / Low Angle / High Angle / Top Shot / Tracking 중에서 서사에 맞게 고른다.
Wide → Medium → Close → Wide 형태로 시각적 호흡을 만든다.
🦸‍♂️🦸‍♂️🦸‍♂️ E3: 같은 샷 크기·같은 카메라 동작 3연속 금지. Wide 계열 40% 초과 시 경고. 20~35초마다 Scale Reveal 1회. 스펙터클은 0:05과 0:40에 배분.

STEP 4. CONTINUITY
각 장면마다 START_STATE / ACTION / END_STATE / NEXT_TRANSITION_OBJECT를 작성한다.
Scene N의 END_STATE는 Scene N+1의 START_STATE로 이어져야 한다.
눈·연기·말·깃발·문·천막·사람·그림자를 전환 브리지로 쓴다.
🦸‍♂️🦸‍♂️🦸‍♂️ E2·A2: 인접 장면의 공통 시각 요소를 35~65%로 맞춘다. 인물은 다음 동작이 가능한 자세로. 진행 방향을 컷마다 뒤집지 않는다.

STEP 5. IMAGE
전체 스타일: cinematic historical painterly illustration, visible broad brush strokes, hand-painted gouache and oil texture, rough paper, cold desaturated blue-gray, muted earth tones, occasional warm amber light, historically grounded, no modern objects, no fantasy armor, no text.
모든 프롬프트는 영어 코드블록. --ar 16:9 포함.
🦸‍♂️🦸‍♂️🦸‍♂️ A3: 1번 장면 하나만 먼저 만든다. 승인 후 그 이미지를 Style Reference로 나머지 전부에 동일하게 붙인다. 왕관·판타지 갑옷·현대 소품·읽히는 문자 금지. 조명은 2계열까지만.

STEP 6. VIDEO
각 Scene N 이미지와 Scene N+1 이미지를 first frame / last frame으로 사용한다.
각 연결마다 영어 영상 프롬프트를 작성하고 primary action 1개, camera movement 1개, transition bridge, physically plausible motion, character consistency, costume consistency, one continuous shot, no jump cuts를 포함한다.
시간 점프는 얼굴 morph가 아니라 foreground occlusion 또는 environmental wipe를 쓴다.
🦸‍♂️🦸‍♂️🦸‍♂️ A4: 시작 0.3~0.6초와 끝 0.3~0.6초는 크게 움직이지 않는다. 물체 수가 바뀌면 실패다. 두 프레임의 공통 요소가 1/3 미만이면 UNSAFE_JOIN으로 보고하고 중간 프레임을 제안한다.

STEP 7. COST
🦸‍♂️🦸‍♂️🦸‍♂️ A5: 장면을 HERO(20% 이하) / EXPLAIN(60%) / GRAPHIC(10%) / STATIC(10%)으로 나눈다.
모든 컷은 저해상도 초안 3~4개(카메라 동작만 변경)를 먼저 만들고 1개를 골라서만 고해상도로 올린다.
기능 지원 여부와 견적 0원을 생성 전에 확인한다. 0원이 아니면 제출하지 않는다. 4K는 업스케일 출력임을 전제한다.

STEP 8. FINAL QC
- 나레이션과 화면 의미가 정확히 맞는가
- 화면 전환 시 문장이 넘어가지 않는가
- 인물 얼굴·복장·손·소품이 변하지 않는가
- Wide가 3회 이상 연속되지 않는가
- 같은 카메라 동작이 3회 반복되지 않는가
- 역사적 오류가 화면에 새로 추가되지 않았는가
- Scene N 마지막 프레임과 Scene N+1 시작이 연결되는가
🦸‍♂️🦸‍♂️🦸‍♂️ 출력 마지막에 좌석별 판정표(좌석 / PASS·REJECT·확인 불가 / 근거 / 최소 수정)를 붙인다.
한 좌석이라도 REJECT면 납품 불가다. 전체 재생성이 아니라 해당 컷만 재생성하는 목록을 낸다.
눈으로 전체를 재생해 확인하지 않은 항목은 PASS가 아니라 "확인 불가"다.
