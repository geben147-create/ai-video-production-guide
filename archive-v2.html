다른 세션에 그대로 전달

기존 영상 문법과 이번 💗01~13을 하나로 합친 범용 지시문입니다. 특정 모델을 강제하지 않고, 설계 후 각 제공자 어댑터가 실제 프롬프트로 번역합니다.

AI 영상 범용 제작 계약 V2
현재 영상의 모델을 먼저 바꾸지 말고 영상 문법과 입력 구조부터 재설계하라.

[IDENTITY]
1. 캐릭터 정본은 머리 없는 전신 정면 / 전신 후면(뒤통수 포함) / 얼굴 클로즈업의 3패널로 만든다. 동일 얼굴 정보를 여러 패널에 반복하지 않는다.
2. 모든 생성 프롬프트 맨 앞에 “얼굴과 의상만 참조 / 참조 배경 사용 금지 / 해당 인물은 정확히 한 명”을 잠근다.
3. duplicate_face, unexpected_person, face drift를 독립 실패 사유로 검사한다.

[NARRATIVE & SHOT]
4. 모든 대사를 PRESENTER_ADDRESS / IN_WORLD_EPISODE / BRIDGED_EPISODE / VOICE_LED_MONTAGE / NO_DIALOGUE 중 하나로 분류한다.
5. 각 장면에 STORY_FUNCTION, SHOT_SIZE, COMPOSITION_TYPE, CAMERA_POSITION, SPATIAL_ANCHOR, SCREEN_DIRECTION을 기록한다.
6. 같은 크기를 이유 없이 반복하지 않는다. 의도된 반복은 허용하고 크기·시점·정보 변화로 컷의 목적을 기록한다. WIDE → OTS → MEDIUM → INSERT → REACTION 중 의미에 맞는 변주를 사용한다.
7. shot_size와 화면 속 인원 관계를 분리한다. SINGLE / TWO-SHOT / THREE-SHOT / GROUP / OTS / INSERT / CUTAWAY / REACTION을 별도 지정한다.
8. 장소 기준 이미지는 정면만 만들지 말고 높은 3/4 또는 측면 공간 마스터를 함께 준비한다. 출입구·카운터·인물 위치·이동 경로를 잠근다.

[CAMERA]
9. 장면 묘사는 SUBJECT+ACTION / SCENE+ENVIRONMENT / VISUAL STYLE로 분리하고 CAMERA 블록을 독립 자산으로 둔다.
10. CAMERA는 MOVEMENT / SPEED / FRAMING LOCK / END STATE 네 요소를 모두 갖는다. END에는 최종 위치, 최종 샷 크기, 감속, 안정 유지 프레임을 명시한다.
11. 한 클립에 카메라 무브먼트는 하나만 사용한다. STATIC도 의도된 기법이다.
12. 카메라는 감정 목적에서 고른다: 각성=dolly in, 압박=slow zoom, 이동 몰입=follow, 걸으며 대사=reverse tracking, 불안=handheld/Dutch, 충격=dolly zoom, 정보 공개=rack focus, 규모=drone pullback.
13. MOVEMENT / ANGLE / SHOT SIZE / COMPOSITION을 서로 다른 축으로 기록한다.

[ACTION & CONTINUITY]
14. 각 영상 프롬프트는 PREVIOUS_STATE → START_STATE → SINGLE_ACTING_BEAT → SPEECH → PHYSICAL_ACTION → CAMERA → END_STATE → CONTINUITY_HANDOFF → NEGATIVE 순서로 작성한다.
15. 걷기·들기·돌기 같은 행동은 앞 컷에서 시작하고 다음 컷에서 마무리하는 CUT_ON_ACTION으로 설계한다.
16. 인물이 이동하면 지나치는 몸, 이동하는 시선, 손·발, 소품, 오프스크린 소리 중 하나로 시간과 거리를 연결한다.
17. 같은 공간은 OTS, 전경 실루엣, 시선 매치 중 하나로 증명한다.
18. CONTINUE만 검증된 END HOLD 프레임을 다음 시작 이미지로 쓴다. 카메라 END와 인물 state_out을 함께 저장한다.

[DURATION & AUDIO]
19. 컷 목적이 길이를 결정한다: 인서트 3–4초 / 이동·액션 5–7초 / 감정·대사 7–10초 / 설정 5–8초 / 의도된 롱테이크만 10초 이상.
20. 모델 최대 길이를 기본값으로 채우지 않는다. 단일 사건 길이로 생성하고 실패한 짧은 컷만 재생성한다.
21. 화면에 보이는 화자는 최종 TTS 오디오 참조 립싱크를 사용한다. 반응이 핵심이면 듣는 인물을 보여주고 화자는 화면 밖에 둔다.
22. 시청자 설명은 상황→선택→결과를 짧게 말한 뒤 극중 행동으로 복귀한다. 모든 대사를 렌즈에 말하지 않는다.

[QC & DELIVERY]
23. 립싱크 QC, 연출 QC, 마지막 1초 END QC, 파일 A/V QC, 비용 QC를 분리한다.
24. 입이 맞더라도 시선·표정·행동 목적·공간·시간·샷 리듬이 틀리면 실패다.
25. 기존 컷은 ACCEPT / EDIT_ONLY / REGENERATE로 분류하고 실패 컷만 다시 생성한다.
26. 장르 스타일은 PROJECT_ADAPTER, Pollo/MiniMax/Kling 필드와 비용은 PROVIDER_ADAPTER에 둔다.
